# Comparação Didática

## Objetivo da Comparação

Comparar uma base simples carregada diretamente no navegador com uma base preparada para desenvolvimento moderno com build tool e módulos organizados.

## Projeto A

- Menor barreira inicial
- Menos arquivos e menos dependências
- Adequado para exemplos curtos
- Mais limitado quando o projeto cresce

## Projeto B

- Scripts padronizados de desenvolvimento
- Melhor base para modularização e expansão
- Introduz ferramenta de build e gerenciamento de dependências
- Aproxima o estudante do fluxo de trabalho usado em projetos reais

## Discussão em Sala

Use esta comparação para avaliar quando a simplicidade inicial compensa e quando o uso de tooling passa a trazer mais benefícios do que custo.
