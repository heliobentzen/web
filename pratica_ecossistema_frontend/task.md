# Atividade - Transição para Ecossistema Front-end Moderno

## Cenário

Uma equipe começou um catálogo de cursos em JavaScript puro, mas agora precisa preparar a base para crescer, reutilizar módulos e adotar um fluxo de desenvolvimento mais produtivo.

## Tarefas

1. Execute `projeto-a` e `projeto-b`.
2. Compare a estrutura de pastas e os pontos de entrada.
3. Identifique o papel de `package.json`, `npm` e `Vite` no segundo projeto.
4. Explique as vantagens e os custos de adotar uma ferramenta de build.
5. Adicione um novo item ao catálogo em ambas as versões.
6. Registre as diferenças observadas na experiência de desenvolvimento.

## Resultado Esperado

Ao final, o grupo deve compreender quando um projeto simples pode permanecer sem build tool e quando faz sentido migrar para uma base com Vite.
