# Guia de Execução e Análise

## Etapa 1

Abra o `projeto-a` no navegador e identifique como os módulos são carregados.

## Etapa 2

No `projeto-b`, instale as dependências e execute o servidor de desenvolvimento.

## Etapa 3

Compare:

- organização de arquivos
- fluxo de execução
- experiência ao alterar o código
- clareza dos scripts disponíveis

## Perguntas Norteadoras

- Em que momento o `package.json` se torna necessário?
- O uso de Vite melhora apenas a execução ou também a manutenção?
- Como a estrutura favorece a evolução para componentes e frameworks?
