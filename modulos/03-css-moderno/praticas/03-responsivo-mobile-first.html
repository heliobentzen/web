Breakpoints Utilizados nesta Página

Esta página demonstra a abordagem Mobile First: os estilos base são escritos para mobile, e media queries adicionam estilos para telas maiores.

Breakpoint Largura mínima Grid de cards Navegação
📱 Mobile 0px 1 coluna Menu hambúrguer
📟 Tablet 768px 2 colunas Nav horizontal
🖥️ Desktop 1024px 3 colunas Nav horizontal

📌 Dica do Dia

Use clamp() para tamanhos de fonte responsivos sem precisar de media queries:

font-size: clamp(1rem, 2.5vw, 2rem);
