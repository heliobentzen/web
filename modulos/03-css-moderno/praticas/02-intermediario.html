Exercício 5: Navigation Bar

Logo Home Sobre Serviços

Código:

<nav style="display: flex; gap: 2rem; align-items: center;">
  <strong>Logo</strong>
  <a href="#">Home</a>
  <div style="flex: 1;"></div> <!-- espaçador -->
  <button>Login</button>
</nav>

Resumo de Propriedades Flexbox

/* Container */
display: flex;
flex-direction: row | column;
flex-wrap: wrap;
justify-content: center | space-between | space-around;
align-items: center;
gap: 1rem;

/* Item */
flex: 1;           /* cresce */
flex: 0 0 200px;   /* largura fixa */
flex-grow: 2;      /* cresce 2x mais */
flex-shrink: 0;    /* não encolhe */
order: 2;          /* ordem visual */
