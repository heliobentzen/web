Variáveis CSS (Custom Properties)

Um sistema de design construído inteiramente com CSS Custom Properties. Clique no botão de tema para ver as variáveis em ação!

Superfícies (mudam com o tema)

--cor-fundo
--cor-superficie
--cor-superficie-2
--cor-borda
:root { --cor-fundo: #f8f9fa; /* claro */ --cor-superficie: #ffffff; --cor-texto: #212529; } [data-tema="escuro"] { --cor-fundo: #0d1117; /* escuro */ --cor-superficie: #161b22; --cor-texto: #e6edf3; }

Design Token

Variáveis CSS são a implementação nativa dos design tokens – valores de design reutilizáveis.

Manutenibilidade

Altere uma variável e o efeito se propaga por todo o sistema. Perfeito para temas.

Performance

Variáveis CSS não requerem pré-processadores. São nativas e suportadas por todos os browsers modernos.

Alertas e Badges

ℹ️ Dica: Você pode ler variáveis CSS com JavaScript usando getComputedStyle(el).getPropertyValue('--variavel').
✅ Sucesso: Variáveis CSS são suportadas em todos os navegadores modernos (Chrome 49+, Firefox 31+, Safari 9.1+).
⚠️ Atenção: Variáveis CSS não funcionam dentro de media queries (@media (min-width: var(--bp)) não funciona).
❌ Evite: Não use !important para sobrescrever variáveis. Ajuste a especificidade do seletor.
