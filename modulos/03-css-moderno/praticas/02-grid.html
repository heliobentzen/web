4. Posicionamento com span e grid-column/row

span 2 linhas
Normal
grid-column: 1 / -1 (largura total)
Normal
Normal
.a { grid-column: span 2; } /* ocupa 2 colunas */
.b { grid-row: span 2; } /* ocupa 2 linhas */
.c { grid-column: 1 / -1; } /* da linha 1 até a última */

5. Áreas Nomeadas – grid-template-areas

Sidebar

Main Content

As áreas nomeadas tornam o layout muito legível.
Você pode ver a estrutura diretamente no CSS!

Footer
grid-template-areas:
  "header header"
  "sidebar main "
  "footer footer";

.header { grid-area: header; }
.sidebar { grid-area: sidebar; }
.main { grid-area: main; }
.footer { grid-area: footer; }
