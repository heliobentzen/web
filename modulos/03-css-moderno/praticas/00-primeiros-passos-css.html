Primeiros Passos com CSS

Esta pagina foi organizada para funcionar como uma mini aula inicial de CSS.

Aqui usamos uma classe para destacar um bloco de texto.

Objetivo: entender seletores, cores, espacamento e tipografia.

Etapa 1 - Tipos de seletores

Elemento: aplica a todos daquele tipo, como h1 e p.

Classe (.): reutilizavel, como .destaque.

ID (#): unico na pagina, como #objetivo.

h1 { color: blue; } .destaque { background: #eff6ff; } #objetivo { color: #0f766e; }

Etapa 2 - Box model na pratica

Este proprio container usa padding, border e max-width.

Com box-sizing: border-box;, o tamanho fica previsivel.

Etapa 3 - Interacao com pseudo-classe

Ao passar o mouse no botao, o estilo muda por causa de button:hover.

Desafio rapido

Edite o arquivo e pratique:

  1. Troque a cor do h1.
  2. Aumente o padding do .container para 32px.
  3. Crie uma nova classe .alerta e aplique em um paragrafo.
