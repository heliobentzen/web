Prática 02 – DOM Intermediário

Manipule o DOM e entenda como JavaScript interage com a página.

Exercício 1: Selecionando Elementos

Vá ao console (F12) e execute:

// Encontre o h1
document.querySelector('h1')

// Encontre todos os buttons
document.querySelectorAll('button')

// Encontre pelo ID
document.getElementById('output')

// Encontre por classe
document.getElementsByClassName('task')
