Prática 02 – Explorando o DOM

Esta página foi criada para você explorar o DOM usando o console do DevTools. Abra o DevTools (F12) e vá para a aba Console.

1. Selecionando Elementos

💻 No console, teste os comandos abaixo: 
// Seletor CSS – retorna o PRIMEIRO elemento que combina
document.querySelector('h1')
document.querySelector('.card')
document.querySelector('#area-interativa')

// Seletor CSS – retorna TODOS os elementos que combinam (NodeList)
document.querySelectorAll('section')
document.querySelectorAll('h2')

// Métodos legados (ainda funcionam)
document.getElementById('area-interativa')
document.getElementsByClassName('card')  // HTMLCollection
document.getElementsByTagName('p')       // HTMLCollection

// Atalhos do console do Chrome/Edge:
// $('seletor')  → mesmo que querySelector
// $$('seletor') → mesmo que querySelectorAll

Identificação dos elementos nesta página: h1, .card, #area-interativa

2. Lendo e Modificando Conteúdo

💻 Experimente no console: 
// Ler o texto de um elemento
document.querySelector('h1').textContent
document.querySelector('h1').innerHTML

// Modificar o texto
document.querySelector('h1').textContent = 'DOM Modificado! 🎉'

// Modificar HTML interno
document.querySelector('#area-interativa').innerHTML =
  '<strong>Conteúdo inserido via JavaScript!</strong>'

// Ler e modificar atributos
const img = document.querySelector('img')
img?.getAttribute('alt')
img?.setAttribute('alt', 'Novo texto alternativo')

// Ler e modificar estilos inline
const titulo = document.querySelector('h1')
titulo.style.color = 'red'
titulo.style.fontSize = '3rem'
titulo.style.transform = 'rotate(-5deg)'

// Adicionar/remover/verificar classes
titulo.classList.add('destaque')
titulo.classList.remove('destaque')
titulo.classList.toggle('destaque')
titulo.classList.contains('destaque')

3. Criando e Inserindo Elementos

💻 Experimente no console: 
// Criar um novo elemento
const novoParagrafo = document.createElement('p')
novoParagrafo.textContent = 'Parágrafo criado via JavaScript!'
novoParagrafo.style.color = 'green'

// Inserir no DOM
const area = document.querySelector('#area-interativa')
area.appendChild(novoParagrafo)        // no final
area.prepend(novoParagrafo)            // no início
area.insertAdjacentHTML('beforeend',
  '<em>Texto inserido com insertAdjacentHTML</em>')

// Remover um elemento
novoParagrafo.remove()

// Clonar um elemento
const clone = document.querySelector('.card').cloneNode(true)
document.body.appendChild(clone)

// Verificar relações na árvore
const secao = document.querySelector('section')
secao.parentElement           // elemento pai
secao.children                // elementos filhos
secao.nextElementSibling      // irmão seguinte
secao.previousElementSibling  // irmão anterior

Esta área é o alvo dos experimentos. Modifique-a!

4. Eventos (introdução)

💻 Experimente no console: 
// Adicionar listener de evento
document.querySelector('h1').addEventListener('click', function(event) {
  console.log('Você clicou no h1!')
  console.log('Evento:', event)
  console.log('Target:', event.target)
})

// Arrow function
document.querySelector('body').addEventListener('mousemove', (e) => {
  console.log(`Mouse em: x=${e.clientX}, y=${e.clientY}`)
})

// Evento de teclado
document.addEventListener('keydown', (e) => {
  console.log(`Tecla pressionada: ${e.key} (código: ${e.code})`)
})

5. Traversal na Árvore DOM

💻 Experimente no console: 
// Navegar pela árvore
const body = document.body

body.children            // HTMLCollection com filhos diretos
body.childNodes          // NodeList incluindo text nodes e comments
body.firstElementChild   // primeiro filho elemento
body.lastElementChild    // último filho elemento

// Contar elementos
document.querySelectorAll('section').length   // número de sections
document.querySelectorAll('*').length         // TODOS os elementos

// Verificar tipo de nó
document.body.nodeType    // 1 = ELEMENT_NODE
document.body.nodeName    // 'BODY'

// closest() – sobe na árvore procurando um seletor
document.querySelector('#log').closest('.card')
document.querySelector('#log').closest('section')
