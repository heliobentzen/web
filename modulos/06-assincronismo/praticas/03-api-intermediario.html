Prática 02 – Fetch e Async/Await

Aprenda a fazer requisições HTTP e lidar com código assíncrono.

Exercício 1: Fetch API Básico

Código:

async function buscarUsuarios() {
  try {
    const response = await fetch('https://jsonplaceholder.typicode.com/users')
    
    if (!response.ok) throw new Error(`HTTP ${response.status}`)
    
    const usuarios = await response.json()
    console.log(usuarios)
  } catch (erro) {
    console.error('Erro:', erro.message)
  }
}

Exercício 2: Tratamento de Erros

Código com try/catch:

async function buscarDados() {
  try {
    const response = await fetch('/url-invalida')
    if (!response.ok) throw new Error(`Erro HTTP: ${response.status}`)
    const data = await response.json()
    return data
  } catch (erro) {
    console.error('Erro capturado:', erro.message)
    return null
  }
}

Exercício 3: Requisição POST (Enviar Dados)

Código:

async function enviarDados() {
  try {
    const response = await fetch('https://jsonplaceholder.typicode.com/posts', {
      method: 'POST',
      headers: {
        'Content-Type': 'application/json'
      },
      body: JSON.stringify({
        title: 'Novo Post',
        body: 'Conteúdo do post',
        userId: 1
      })
    })
    
    const data = await response.json()
    console.log('Resposta:', data)
  } catch (erro) {
    console.error('Erro:', erro)
  }
}

Exercício 4: Múltiplas Requisições (Promise.all)

Código:

async function multiplosRequests() {
  try {
    const [usuarios, posts, comentarios] = await Promise.all([
      fetch('https://jsonplaceholder.typicode.com/users').then(r => r.json()),
      fetch('https://jsonplaceholder.typicode.com/posts').then(r => r.json()),
      fetch('https://jsonplaceholder.typicode.com/comments').then(r => r.json())
    ])
    
    console.log(`${usuarios.length} usuários`)
    console.log(`${posts.length} posts`)
    console.log(`${comentarios.length} comentários`)
  } catch (erro) {
    console.error('Erro:', erro)
  }
}

Exercício 5: JSON Parse e Stringify

Código:

// JSON.stringify: Objeto → String
const usuario = { nome: 'João', idade: 30 }
const json = JSON.stringify(usuario)
console.log(json)  // '{"nome":"João","idade":30}'

// JSON.parse: String → Objeto
const str = '{"nome":"Maria","idade":25}'
const obj = JSON.parse(str)
console.log(obj.nome)  // "Maria"

Resumo: Async/Await vs Promises

Com Promises (antigo):

fetch('/api/users')
  .then(r => r.json())
  .then(data => console.log(data))
  .catch(erro => console.error(erro))

Com Async/Await (moderno):

async function exemplo() {
  try {
    const r = await fetch('/api/users')
    const data = await r.json()
    console.log(data)
  } catch (erro) {
    console.error(erro)
  }
}

Vantagem: Async/await é mais limpo e fácil de entender.
