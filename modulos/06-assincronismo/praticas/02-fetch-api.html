Prática 02 – Fetch API

Demonstrações interativas de GET, POST, PUT, DELETE usando a JSONPlaceholder – uma API fake gratuita para testes.

1. GET – Listar Usuários

Endpoint: GET /users

2. GET com Parâmetros

Endpoint: GET /posts?userId={id}

3. POST – Criar Recurso

Endpoint: POST /posts

4. PUT / PATCH – Atualizar

PUT substitui o recurso inteiro. Todos os campos são obrigatórios.

PATCH atualiza apenas os campos enviados.

5. DELETE – Excluir

Endpoint: DELETE /posts/{id}

6. AbortController – Cancelar Requisição

Permite cancelar uma requisição em andamento.
