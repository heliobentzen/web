HTML Semântico: Por que Importa?

Por
João Silva
 15 jan. 2024 HTML SEO Acessibilidade

O HTML semântico vai além de simplesmente estruturar visualmente uma página. Ao usar as tags corretas, você comunica o significado do conteúdo tanto para navegadores quanto para tecnologias assistivas e mecanismos de busca.

Por que usar elementos semânticos?

Existem três grandes beneficiários do HTML semântico:

  1. Acessibilidade: leitores de tela usam a estrutura do HTML para navegar pela página
  2. SEO: buscadores entendem melhor a relevância do conteúdo
  3. Manutenibilidade: código mais legível e organizado

A diferença entre <div> e elementos semânticos

Autores são encorajados a usar elementos que descrevem melhor o conteúdo, em vez de usar o elemento div para tudo.

— HTML Living Standard, WHATWG

Um leitor de tela que encontra um <nav> sabe que aquele bloco é uma navegação e pode anunciá-lo ao usuário. Um <div class="nav"> não transmite essa informação automaticamente.

Estrutura de uma página típica

A estrutura mais comum de uma página HTML5 semântica inclui: header, nav, main, article ou section, aside e footer. Cada elemento tem um papel claro na hierarquia do documento.
