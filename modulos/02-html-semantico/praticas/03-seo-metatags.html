Guia de HTML Semântico para SEO em 2024

Por João Silva 15 jan. 2024 Atualizado: 20 jan. 2024 HTML SEO Metadados

O SEO técnico em HTML vai muito além de colocar palavras-chave no conteúdo. Os metadados corretos ajudam os mecanismos de busca a indexar sua página, melhoram a aparência nos resultados de busca (SERP) e controlam como sua página é exibida ao ser compartilhada nas redes sociais.

1. Metadados Básicos

Title e Description

<title>Guia de HTML Semântico para SEO | TechBlog</title>
<meta name="description" content="Aprenda metadados, Open Graph e dados estruturados...">
  • <title>: 50–60 caracteres, palavra-chave no início
  • description: 150–160 caracteres, ação clara
  • Nunca duplique titles entre páginas
  • O Google pode reescrever seu title/description — seja relevante

Canonical e Robots

<link rel="canonical" href="https://example.com/pagina-principal">
<meta name="robots" content="index, follow">
DiretivaEfeito
indexPermite indexação (padrão)
noindexNão indexa a página
followSegue links (padrão)
nofollowNão passa PageRank pelos links
noarchiveNão armazena cópia em cache

2. Open Graph

O protocolo Open Graph controla como sua página aparece quando compartilhada no Facebook, LinkedIn, WhatsApp e outras plataformas. 

<meta property="og:type" content="article">
<meta property="og:url" content="https://example.com/artigo">
<meta property="og:title" content="Título ao Compartilhar">
<meta property="og:description" content="Descrição ao compartilhar.">
<meta property="og:image" content="https://example.com/og-image.jpg">
<meta property="og:image:width" content="1200">
<meta property="og:image:height" content="630">
💡 Imagem OG ideal: 1200×630px, JPG ou PNG, até 8MB. Teste sua página em Sharing Debugger do Facebook.

3. Twitter / X Cards

<meta name="twitter:card" content="summary_large_image">
<meta name="twitter:site" content="@meusite">
<meta name="twitter:title" content="Título no Twitter">
<meta name="twitter:description" content="Descrição no Twitter.">
<meta name="twitter:image" content="https://example.com/twitter.jpg">
⚠️ Twitter Cards têm seu próprio validador: cards-dev.twitter.com/validator

4. Dados Estruturados (Schema.org)

Os dados estruturados em JSON-LD permitem ao Google exibir rich results: estrelas de avaliação, preços, FAQs, eventos, etc.

Tipos mais comuns

TipoRich Result
ArticleCarrossel de notícias, AMP
ProductPreço, disponibilidade, avaliações
FAQPagePerguntas e respostas no SERP
LocalBusinessPainel de conhecimento, Google Maps
RecipeInformações da receita, avaliações
EventData, local e link do evento
BreadcrumbListMigalhas de pão no SERP

5. Checklist de SEO Técnico

  • Title único por página, 50-60 caracteres
  • Meta description atrativa, 150-160 caracteres
  • URL canônica definida
  • Hierarquia de headings correta (h1 único)
  • Imagens com alt text descritivo
  • Links com texto descritivo (não "clique aqui")
  • Open Graph configurado
  • Twitter Cards configurado
  • Dados estruturados relevantes
  • Sitemap XML presente e enviado ao Search Console
  • robots.txt configurado corretamente
  • HTTPS ativo
  • Site mobile-friendly
  • Core Web Vitals dentro dos limites

Perguntas Frequentes

O que é HTML semântico?

HTML semântico é o uso de elementos HTML que descrevem claramente seu significado tanto para o navegador quanto para o desenvolvedor e ferramentas de acessibilidade.

HTML semântico melhora o SEO?

Sim. Mecanismos de busca entendem melhor a estrutura do conteúdo quando você usa elementos semânticos como article, section, h1–h6, etc.
