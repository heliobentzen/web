Exercício 1: Arrays e Métodos

Código:

const numeros = [1, 2, 3, 4, 5]

// map: transformar cada elemento
const dobrados = numeros.map(n => n * 2)
console.log(dobrados) // [2, 4, 6, 8, 10]

// filter: manter apenas alguns elementos
const pares = numeros.filter(n => n % 2 === 0)
console.log(pares) // [2, 4]

// reduce: combinar em um valor
const soma = numeros.reduce((acc, n) => acc + n, 0)
console.log(soma) // 15

// find: encontrar primeiro elemento
const primeiro3 = numeros.find(n => n > 3)
console.log(primeiro3) // 4

Abra o DevTools (F12) → Console para ver os resultados.

Exercício 2: Objetos e Desestruturação

const usuario = { nome: 'João', idade: 30, email: 'joao@example.com' }

// Acessar propriedades
console.log(usuario.nome)     // "João"
console.log(usuario['idade'])  // 30

// Desestruturação
const { nome, idade } = usuario
console.log(nome, idade)  // "João" 30

// Spread operator
const novoUsuario = { ...usuario, cidade: 'São Paulo' }
console.log(novoUsuario)
// { nome: 'João', idade: 30, email: '...', cidade: 'São Paulo' }

Exercício 3: Lista TODO Interativa

    Código:

    let tarefas = []

function adicionarTarefa() {
  const input = document.getElementById('novasTarefa')
  const tarefa = input.value.trim()
  
  if (tarefa === '') return
  
  tarefas.push({ id: Date.now(), texto: tarefa, concluida: false })
  input.value = ''
  renderizarTarefas()
}

function renderizarTarefas() {
  const lista = document.getElementById('listaTarefas')
  lista.innerHTML = tarefas.map(t => `
    <li>${t.texto}</li>
  `).join('')
}

    Exercício 4: Event Delegation

    Clique nos botões abaixo - observe como event delegation funciona:

    Por que Event Delegation?

    • Menos listeners (1 ao invés de N)
    • Elementos criados dinamicamente funcionam automaticamente
    • Melhor performance em listas grandes
    // Ao invés de adicionar listener em cada botão:
// botao1.addEventListener('click', ...)
// botao2.addEventListener('click', ...)

// Adicione um único listener no container:
container.addEventListener('click', (e) => {
  if (e.target.classList.contains('botao-dinamico')) {
    console.log('Botão clicado:', e.target.textContent)
  }
})
