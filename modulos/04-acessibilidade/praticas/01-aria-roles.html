1. Landmarks HTML5 e ARIA

💡 Landmarks são elementos que definem regiões da página. Leitores de tela os usam para navegação rápida. Pressione D no NVDA ou W no VoiceOver para navegar entre landmarks.

Mapa de Landmarks desta página

<nav> / role="navigation" Menu

Conteúdo complementar

Conteúdo principal (único por página)
<footer> / role="contentinfo"

3. Padrões de UI Acessíveis

Tabs (Abas) – ARIA Pattern

O HTML define a estrutura semântica da página com elementos como <header>, <main>, <article>.

O CSS define a apresentação visual. Use :focus-visible para indicadores de foco acessíveis.

JavaScript adiciona interatividade. Gerencie aria-expanded, aria-selected e foco do teclado.

💡 Navegue entre as abas com as ← → do teclado!

Acordeão – Usando <details> e <summary>

<details> e <summary> são acessíveis nativamente, sem JavaScript!

O que é WCAG?
WCAG (Web Content Accessibility Guidelines) são as diretrizes internacionais de acessibilidade web publicadas pelo W3C. A versão atual é WCAG 2.2 (2023).
O que é ARIA?
ARIA (Accessible Rich Internet Applications) é uma especificação W3C que define atributos HTML para adicionar semântica de acessibilidade a elementos que não a possuem nativamente.
Por que acessibilidade beneficia a todos?
Acessibilidade melhora a experiência para todos: usuários com deficiência, idosos, usuários em dispositivos diferentes, com conexão lenta, ou simplesmente em situações adversas como sol forte ou mãos ocupadas.

Modal / Dialog Acessível

Um modal acessível deve: gerenciar foco, aprisionar o Tab, fechar com Esc, e usar role="dialog".
