# Atividade - Auditoria e Evolução de Código Front-end

## Cenário

Sua equipe recebeu duas versões de uma aplicação web que consulta tarefas públicas e exibe os resultados na interface.

As duas versões funcionam, mas foram construídas com níveis diferentes de organização. A proposta é analisar a qualidade técnica de cada uma, identificar limitações e propor uma evolução orientada pelos conteúdos dos módulos 05 e 06.

## Tarefas

1. Execute os dois projetos e registre o comportamento de cada um.
2. Compare a organização do código entre `projeto-a` e `projeto-b`.
3. Identifique trechos com baixa coesão, alto acoplamento ou responsabilidades misturadas.
4. Analise como cada versão trata:
   - eventos
   - manipulação de DOM
   - assincronismo
   - tratamento de erro
   - feedback visual ao usuário
5. Proponha ao menos três melhorias objetivas e justificadas.
6. Implemente uma melhoria adicional em um dos projetos e descreva o impacto da mudança.

## Critérios de Discussão

- O código está fácil de entender?
- A separação de responsabilidades está adequada?
- O tratamento de erro melhora ou prejudica a experiência do usuário?
- Qual versão oferece uma base mais segura para evoluir com novas funcionalidades?

## Resultado Esperado

Ao final, o grupo deve conseguir justificar tecnicamente qual abordagem oferece melhor base para continuidade do projeto e quais mudanças seriam prioritárias.
