# Versão Corrigida - Direção Esperada

## Direção Esperada

Uma solução mais consistente para esta atividade deve apresentar:

- funções pequenas e com propósito claro
- separação entre leitura de dados e atualização de interface
- tratamento explícito de loading, sucesso e erro
- nomes consistentes para eventos, seletores e estado
- possibilidade de reaproveitar partes do código sem depender da página inteira

O `projeto-b` representa a direção estrutural mais próxima dessa abordagem.
